# Historial
- **v1** KB estática de 55 temas + autoscroll + landing pública (sin API key).
- **v2** NicoBot: 30+ intenciones, cálculos (7 %, tramo Fonasa, deducible CAEC), clasificador con olvido oncológico, datos por isapre. Simulación 10.000 conv. (99,6 %).
- **v3** Cortafuegos salud mental; capa conversacional (empatía, vago, ¿bot?, desambiguar, multi‑pregunta); orientación a comparar para afiliables; identidad "asistente".
- **v4** Calificación una pregunta a la vez, pros personalizados del cambio, objeciones (conforme, miedo, qué pierdo, cuándo, ahorro, cobran, documentos), `humanizar()`; temas nuevos: complementario, catastrófico, topes, Ricarte Soto, GES, CAEC, urgencia, grupos económicos, Superintendencia; **voz** (Web Speech API es‑CL) y números hablados.
- **v5** **Auditoría de datos con fuentes oficiales**: tope imponible 90 UF, tramos Fonasa, alza 2026 (y plazo ya vencido), venta Banmédica, ILC/Consalud, Circulares 396/354/476/534, Ley Corta 21.674, CAEC 43 cotizaciones/181 UF, Ricarte Soto (27, sin nuevas desde 2021), eliminado "25 %" no respaldado y plazos de retracto no encontrados.
- **v6** **Traspaso de leads** (contact.js + notify por etapas + resumen + tier), WhatsApp sin datos de salud, re‑enganche, validación/anti‑bots en backend. Paquete para Claude Code con 15 pruebas.
- **v6.1** (12‑oct‑2026, Claude Code) Prueba de humo remota `npm run smoke` (descarga el motor publicado y corre los barridos de salud mental y cifras contra producción); panel de depuración solo con `?debug=1`; **UF del día** desde mindicador.cl con caché diaria en `localStorage` y fallback a 41.000 (motor sigue offline: `NicoBot.setUF()`/`uf()`); `guard()` también en `netlify/functions/chat.js` sobre la respuesta del modelo; set a ciegas 5 (25 frases: cambio, alzas, urgencia, licencias, seguros, Fonasa, cargas) que medía 76 % → reglas nuevas en `concept()` → 100 % y pasa a regresión. Batería: 20 pruebas.
